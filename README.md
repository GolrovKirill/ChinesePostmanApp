# 📬 Решение задачи о китайском почтальоне

Данный проект представляет собой программную реализацию классической задачи теории графов — **задачи о китайском почтальоне** (или задачи о проверке дорог). Цель программы — найти кратчайший замкнутый маршрут, который проходит через каждое ребро графа хотя бы один раз.

---

## 🌟 Основные возможности

*   **Интуитивный интерфейс**: Удобная форма с крупными элементами управления, адаптированная под современные мониторы.
*   **Автоматизация расчетов**: Программа сама определяет нечетные вершины и находит оптимальные пути для их "замыкания".
*   **Валидация данных**: Проверка на связность графа и корректность ввода вершин.
*   **Встроенные тесты**: Две кнопки для мгновенной загрузки классических примеров (Эйлеров цикл и граф с нечетными вершинами).

---
