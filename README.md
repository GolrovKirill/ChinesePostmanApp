Решение задачи о китайском почтальоне
Данное приложение предназначено для нахождения кратчайшего замкнутого маршрута в неориентированном связном графе, который включает каждую дугу (ребро) по крайней мере один раз.
🚀 Особенности
Алгоритмическая база: Использование алгоритма Флойда-Уоршелла для поиска кратчайших путей и рекурсивного поиска минимального совершенного сочетания для нечетных вершин.
Интерфейс: Удобное графическое окно на Windows Forms с крупными элементами управления.
Валидация: Проверка графа на связность и наличие всех заявленных вершин.
Тестирование: Встроенные кнопки для быстрой загрузки тестовых сценариев (Эйлеров граф и классическая задача почтальона).
🛠 Требования
Для запуска и сборки проекта вам понадобятся:
Visual Studio 2022 (или новее) или Visual Studio Code.
Среда .NET 9.0 SDK.
Операционная система Windows (так как используется библиотека System.Windows.Forms).
📦 Развертывание и запуск
1. Клонирование репозитория
Откройте терминал (или Git Bash) и выполните команду:
code
Bash
git clone git@github.com:GolrovKirill/ChinesePostmanApp.git
cd ChinesePostmanApp
2. Запуск через Visual Studio
Найдите файл проекта (с расширением .csproj или .sln) и откройте его.
Убедитесь, что в верхней панели выбрана конфигурация Debug или Release.
Нажмите кнопку Start (или клавишу F5).
3. Запуск через терминал (.NET CLI)
Если у вас установлен .NET SDK, вы можете запустить приложение командой:
code
Bash
dotnet run
📖 Как пользоваться программой
Задайте количество вершин: Введите число в поле "1. Укажите общее кол-во вершин".
Добавьте дороги (рёбра):
Введите номер начальной вершины.
Введите номер конечной вершины.
Укажите вес (длину) дороги.
Нажмите "ДОБАВИТЬ В ГРАФ".
Рассчитайте маршрут: Нажмите зеленую кнопку "ВЫЧИСЛИТЬ КРАТЧАЙШИЙ МАРШРУТ".
Анализ результата:
В правом окне отобразится суммарный вес всех ребер.
Если есть нечетные вершины, программа покажет их список и добавочный вес, который необходимо пройти повторно.
Итоговое значение — это кратчайший замкнутый путь.
Быстрый старт (Тесты)
Для ознакомления используйте кнопки:
ТЕСТ 1: Загружает идеальный эйлеров граф (квадрат), где не нужно проходить по ребрам дважды.
ТЕСТ 2: Загружает граф с "хвостом", демонстрируя поиск оптимального пути между нечетными вершинами.
